Koneksi Cloud Firestore & Auth

Sinkronisasi real-time ke database Cloud Firestore

Isi Otomatis dari Kode `firebaseConfig`

Lihat di Firebase Console → Project Settings → Project ID.

Kredensial Login Admin & Mandor

Lihat Rules Cloud Firestore (Salin ke Tab Rules) 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

Jika sudah mengaktifkan Firebase Auth (Email/Password), Anda bisa mengganti if true; menjadi if request.auth != null;.
